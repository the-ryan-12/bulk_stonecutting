# Bulk Stonecutting

Client-only Fabric mod that speeds up repeated stonecutter crafting.

Download: [Modrinth](https://modrinth.com/mod/bulk-stonecutting)

## Requirements

- Minecraft **26.2** (stable)
- Fabric Loader **>= 0.19.3**
- Fabric API **0.156.0+26.2**
- Java **25**

Install on the **client** only. Not intended for dedicated servers.

## Usage

1. Open a stonecutter.
2. Enable **Mass crafting** in the UI.
3. Shift-left-click a recipe output.

While Mass crafting is on, the mod refills matching input from your inventory and reselects the recipe so you can keep crafting. The checkbox state lasts for the current session only (it is not saved).
