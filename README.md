# Bulk Stonecutting

Client-only Fabric mod that speeds up repeated stonecutter crafting. It can get really irritating when you want to craft many stacks of some sort of stone and you have to do 3 clicks for each stack you wish to craft. This is built to solve it and allow for quickly crafting as many stacks as you need. For convenience, if your inventory is full, it will drop the item stack just crafted onto the ground to allow for larger-than-inventory quantities of crafting.

Download: [Modrinth](https://modrinth.com/mod/bulk-stonecutting)

## Usage

1. Open a stonecutter.
2. Enable **Auto Refill** in the UI.
3. Shift-left-click a recipe output.

While Auto Refill is on, the mod refills matching input from your inventory and reselects the recipe so you can keep crafting. 

## Requirements

- Minecraft **26.2** (stable)
- Fabric Loader **>= 0.19.3**
- Fabric API **0.156.0+26.2**
- Java **25**
